# 🍁 대동주택 스마트 월세관리 앱 (Flutter / Android)

소규모 임대인을 위한 안드로이드 전용 스마트 월세 관리 앱입니다.  
스마트폰에 은행 입금 문자가 도착하면 백그라운드에서 자동 감지하여 **2달치(초과) 입금 시 당월 완납 + 익월 선납**까지 스마트폰 안에서 100% 자동 처리합니다.

---

## 🎨 디자인 테마
- **가을 감성 테마 (Autumn Cozy Palette)**:
  - 깊은 단풍빛 테라코타 (Maple Red/Brown)
  - 황금빛 앰버 (Warm Amber)
  - 포근한 크림 오트밀 (Cozy Cream)
  - 에스프레소 다크 텍스트

---

## 🏢 대동주택 호실 구성 (총 16세대)
- **2층**: 201호, 202호, 203호, 204호
- **3층**: 301호, 302호, 303호, 304호
- **4층**: 401호, 402호, 403호, 404호
- **5층**: 501호, 502호, 503호, 504호

---

## ⚙️ 주요 기능
1. **SMS 자동 감지 (백그라운드 리시버)**:
   - `[KB] 11/12 201호 김민수 입금 1,000,000원` 문자 수신 시 자동 인식
2. **다중 월 선납 충당 엔진**:
   - 100만 원 입금 시: 이번 달 50만 원 완납 + 다음 달 50만 원 선납 완납 자동 기록
3. **상단 푸시 알림 (Push Notification)**:
   - "🍂 [대동주택 201호] 100만원 입금 완료 (11월 완납 / 12월 선납)"
4. **원클릭 통화 연동**:
   - 미납 호실 세입자에게 터치 한 번으로 바로 전화 걸기

---

## 📦 APK 설치 파일 빌드 및 스마트폰 설치 방법

```bash
# 1. 패키지 의존성 다운로드
flutter pub get

# 2. 안드로이드 설치용 APK 빌드
flutter build apk --release
```

빌드가 완료되면 아래 경로에 설치 파일이 생성됩니다:
`build/app/outputs/flutter-apk/app-release.apk`

이 `app-release.apk` 파일을 스마트폰(갤럭시)으로 전송하여 터치하면 설치가 완료됩니다!
